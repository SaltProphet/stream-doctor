## Packaged GUI startup regression

Root cause of the startup failure: `build_windows.ps1` passed `stream_doctor/app.py` directly to PyInstaller. PyInstaller then executed it as the top-level `app` module, so its imports such as `from .core import ...` had no package parent. The fix is `launcher.py`, which imports `stream_doctor.app` using its qualified package name. The build now removes stale `build`, `dist\StreamDoctor`, and `.spec` outputs before building `launcher.py`.

## Optimizer and network milestone

The optimizer now consumes a shared measurement model and exposes explicit Apply/Rollback controls. The apply path only supports measured bitrate recommendations, requires an explicit confirmation, refuses to run while OBS reports an active stream, reads settings back from OBS, and retains only non-secret backup values for rollback.
